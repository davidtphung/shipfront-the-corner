# Shipfront: The Crate

Freight operating system marketing site.

Live narrative: bookings, carriers, documents, exceptions, and tracking in one workspace.

## Stack

- Next.js 15 (static export)
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Geist + Geist Mono

## Scripts

```bash
npm install
npm run dev
npm run build
```

`npm run build` writes a static site to `out/`.

## Voice

Specific and operational. No "revolutionize", "leverage", "seamless", "game-changing", or "unlock".

Sample figures on the page are labeled as sample product content.
